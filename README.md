# 合成大西瓜 · 超果冻版

一款可在手机或桌面浏览器中游玩的轻量合成水果游戏：放下水果、合并同类项，在物理碰撞与连击中挑战更高分数。

## 怎么玩

1. 打开游戏并点击“开始游戏”。
2. 在游戏区域点击或拖动，选择落点并放下当前水果。
3. 两个相同的水果碰在一起时会合成为更高一级的水果；连续合成可触发连击加分。
4. 留意水果堆叠高度，避免越过危险线。游戏结束后可查看本局得分、历史最高分和本局合成到的最高水果，并选择再玩一局。

游戏包含得分与下一个水果预览、音效开关、重新开始按钮，以及复制战绩文本的操作。最高分和音效设置保存在当前浏览器的本地存储中。

## 界面与交互

- 以竖屏游戏区域为核心，适配较窄的手机视口；游戏画面绘制在 Canvas 上。
- 暖色渐变背景、半透明信息面板和果冻质感水果构成轻松的视觉风格。
- 开始页、实时 HUD 和结算卡片分别呈现操作提示、当前/历史得分、下一个水果、最大合成结果与再玩入口。
- 支持触控指针操作，并提供由 Web Audio API 合成的碰撞、合成、连击和结算音效；可单独静音。

## 技术栈

- 原生 HTML、CSS 与 JavaScript
- Canvas 2D：绘制水果、游戏场景与特效
- Matter.js 0.19.0：水果碰撞与物理模拟（仓库内含 `matter.min.js`）
- Python 3：运行 `build.py` 生成单文件页面

## 运行

无需安装 npm 依赖或启动后端。直接用现代浏览器打开仓库根目录的 `合成大西瓜.html` 即可游玩。

如需从拆分源码重新生成单文件页面，在仓库根目录运行：

```bash
python3 build.py
```

脚本会根据 `markup.html`、`style.css`、`game.js` 和 `matter.min.js` 重建 `合成大西瓜.html`。GitHub Pages 的工作流也会在手动触发时构建该页面并部署；它不会因普通推送自动运行。

## 仓库文件

- `合成大西瓜.html`：可直接打开的单文件游戏页面
- `markup.html`：页面结构模板
- `style.css`：游戏样式
- `game.js`：游戏逻辑、绘制与交互
- `matter.min.js`：Matter.js 压缩构建
- `build.py`：将模板、样式和脚本内嵌为单文件页面
- `.github/workflows/deploy-pages.yml`：手动触发的 GitHub Pages 部署工作流
